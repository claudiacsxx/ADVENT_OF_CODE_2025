AUTOEVALUACIÓN
  ELECCIÓN DEL PROBLEMA
    Consideramos que todos los problemas que hemos elegido han sido resueltos con la técnica adecuada, y todos son buenos ejemplos del uso de cada técnica para facilitar la resolución de una cuestión compleja. 
  CÓDIGO
    Hemos comprobado que todos los códigos resuelven tanto los ejemplos otorgados en cada problema como los inputs complejos finales, por lo que son completamente funcionales y llevan a la solución correcta. 
  CALIDAD ALGORÍTMICA Y EFICIENCIA
    Independientemente de que se puedan resolver los códigos con fuerza bruta, nos hemos esforzado para buscar la mejor solución utilizando las técnicas y herramientas aprendidas en clase este curso (divide y vencerás, programación dinámica - memoización, tablas hash, grafos...) para conseguir un código óptimo, eficiente y, sobretodo, correcto.
  DISEÑO Y CLARIDAD DEL CÓDIGO
    Nuestros códigos están apropiadamente comentados, con explicaciones paso a paso de lo que se está haciendo, además de tabulaciones acordes y nombres de tanto funciones como variables adecuados para su uso. 
  MEMORIA
    Las razones por las que hemos elegido estos códigos están totalmente justificadas en los READMEs acordes a cada problema, ofreciendo argumentos que respaldan nuestras elecciones.
  DESCRIPCIÓN TÉCNICA
    Cada código tiene consigo una descripción técnica extensiva en la que se explica el funcionamiento del código y cómo se ha planteado la solución del problema. 
  ALTERNATIVAS
    Además, en cada problema se muestran soluciones alternativas que planteamos antes de decidir usar la mostrada en el código, y la explicación de por qué se decidió usar la elegida y no la alternativa. 
  VALORACIÓN PERSONAL
    Finalmente, en cada código se ha añadido un apartado de comentarios personales en los que explicamos cómo nos ha servido la realización de estos problemas para nuestros conocimientos en la asignatura y desarrollo personal en el ámbito de programación.
